# Vonage Video API x Mastra starter

This application is intended to be to help developers integrate the [Vonage Video API](https://developer.vonage.com/en/video/overview?source=video) into a [Mastra](https://mastra.ai/) application.

## Features

- Uses the Vonage Video API [Audio Connector](https://developer.vonage.com/en/video/guides/audio-connector) to send and receive audio between a video call and the [AI Voice Agent](https://mastra.ai/reference/voice/overview) on Mastra
- Text chat with an AI Agent
- Using Mastra [Tools](https://mastra.ai/docs/agents/tools) and the Vonage Video [Signaling API](https://developer.vonage.com/en/video/guides/signaling?source=video) the AI Agents (both voice and text) can call a tool that will open a dialog modal in the application
- The Vonage Video Signaling API is used to display the real-time transcript generated by the the Mastra AI Voice Agent to be used as captions

## Get started

The easiest way to run this application is by using GitHub Codespaces. This sets up the entire environment automatically in your browser.

1. **Fork this repository** to your own GitHub account.
2. In your new fork, click the green **<> Code** button at the top right of the files list.
3. Select the **Codespaces** tab.
4. Click **Create codespace on main**.

Once the environment loads, the setup script will run automatically to configure your Vonage application!

The setup script will create the Vonage Application needed for the Video chat. It will ask for API Key and API Secret which can be found in the [Vonage Dashboard](https://dashboard.vonage.com)

Once the step script is completed, you may get an error as the application starts up saying that you are missing an AI API Key.

> **Note:** This application was created using Google Gemini models. You can get an API Key in the Google [AI Studio dashboard](https://aistudio.google.com/). Mastra supports a wide array of [models](https://mastra.ai/models) and list their corresponding [environment variables](https://mastra.ai/models/environment-variables).

If you are using Google Gemini, your application should be up and running. If not, you will need to change the LLM models in:

- src/mastra/agents/agent.ts (AI Text Agent)
- src/wsBridge.ts (AI Voice Agent)
